# Offline completo fuera del MVP

El MVP no implementara operacion offline completa ni sincronizacion de conflictos. La aplicacion MVP funcionara conectada y permitira adjuntar evidencias desde navegador, pero el dominio y la arquitectura no deben impedir la futura PWA o app offline definida para V1. Esta decision reduce complejidad inicial sin abandonar el requisito de campo sin conexion registrado previamente.
