# Dataset piloto del MVP

El MVP se validara con un proyecto piloto simulado pero realista, no con un proyecto real con obligaciones vivas. El dataset incluira un proyecto, una fase de construccion, cuatro partidas, dos subcontratos, dos avances por partida, una no conformidad, dos estimaciones y evidencias ficticias o no sensibles. Esto permite validar el flujo principal sin exponer informacion sensible ni depender de una obra activa.
