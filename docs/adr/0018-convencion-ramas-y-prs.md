# Convencion de ramas y Pull Requests

Las ramas del MVP usaran el formato `dev/linear-id-descripcion-corta` para desarrolladores humanos y `codex/linear-id-descripcion-corta` para trabajo de agentes. Los Pull Requests usaran titulos con el identificador de Linear, por ejemplo `[CIV-123] Descripcion clara`, e incluiran que cambia, como se probo, enlace al issue, capturas cuando haya UI y notas de migracion cuando cambie la base de datos.
