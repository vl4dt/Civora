# Exportacion contable antes de integracion directa

La primera version entregara exportaciones contables configurables en lugar de integrarse directamente con un sistema contable externo. Esta decision reduce dependencia temprana de un proveedor contable mientras se estabilizan los procesos internos de costos, ingresos, cierres y aprobaciones; la integracion directa queda reservada para una segunda version.
