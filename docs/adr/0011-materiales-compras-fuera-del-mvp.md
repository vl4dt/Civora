# Materiales y compras fuera del MVP operativo

El MVP no implementara compras, inventario, consumo real, transferencias ni desviaciones de materiales. Las fichas de rendimiento pueden incluir materiales como referencia presupuestaria, pero el control operativo de materiales queda para V1 posterior. Esta decision protege el tracer bullet del MVP, centrado en avance aceptado, estimacion y costo del proyecto.
