# Definition of Done

Un issue del MVP solo puede marcarse como Done cuando el codigo esta mergeado a main, las migraciones aplicables fueron probadas en staging, las pruebas relevantes pasan, el PR contiene evidencia de prueba, el cambio fue desplegado a staging, el Product Owner valido funcionalmente cuando afecta el flujo de negocio y la documentacion fue actualizada si cambio el dominio o una decision.
