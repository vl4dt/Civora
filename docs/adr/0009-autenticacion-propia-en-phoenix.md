# Autenticacion propia en Phoenix para el MVP

El MVP usara autenticacion propia en Phoenix con usuarios internos, email, contrasena, recuperacion de contrasena y sesiones web seguras. Se evita incorporar un proveedor externo de autenticacion durante el MVP porque el uso inicial sera interno y propietario; SSO o autenticacion externa podran evaluarse despues para portales de clientes y subcontratistas.
