# Estructura Linear del MVP

El seguimiento del MVP se organizara en Linear con una iniciativa `Civora` y un unico proyecto `Civora MVP`, dividido en milestones: decision tecnica, base operativa, presupuesto y partidas, subcontrato y avance, calidad y avance pagable, estimacion y costo, y piloto interno. Se evita crear multiples proyectos para el MVP porque el objetivo es mantener foco y trazabilidad sobre un flujo vertical completo.
