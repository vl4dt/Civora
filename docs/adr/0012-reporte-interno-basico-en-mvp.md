# Reporte interno basico en el MVP

El MVP incluira un reporte interno basico en pantalla con proyecto, presupuesto aprobado, subcontrato, avance ejecutado, avance pagable, no conformidades abiertas, estimaciones y costo acumulado. No incluira PDF formal, reportes publicados, reporte del cliente ni tablero de cartera; esos elementos quedan para V1 posterior despues de validar el flujo operativo principal.
