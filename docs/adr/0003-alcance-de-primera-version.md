# Alcance inicial centrado en control integral de proyecto

La primera version se enfocara en controlar proyectos, presupuestos, subcontratos, calidad, materiales, compras, bitacora, evidencias, reportes, finanzas, cierres mensuales y portales limitados para cliente y subcontratista. Se excluyen de inicio portal de proveedores, maquinaria, asistencia individual, habilitacion de trabajadores, integraciones contables, gestion legal avanzada, firma avanzada e importacion automatica de comunicaciones para validar primero el flujo operativo y financiero principal sin dispersar el producto.
