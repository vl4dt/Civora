## Notes

The Linear workspace currently exposes default statuses: `Backlog`, `Todo`, `In Progress`, `In Review`, `Done`, plus cancellation/duplicate states. The planned `Ready`, `Staging`, and `Blocked` states from `MVP_EXECUTION_RULES.md` should be configured manually in Linear if workspace permissions allow it. Until then, use labels and comments to represent those transitions.
